Rules how cells and verdicts are colored
  • SNP+RC error, GW×ceil, gene-window error %: better / worse when the change vs baseline is ≥ 5% relative and ≥ 0.01 pp (SNP+RC), ≥ 0.05× (GW×ceil) or ≥ 0.005 pp (gene-window %); otherwise similar.
  • R→C (random → ceiling %): 100 × (random − model) ÷ (random − ceiling) on gene-window error; 0 = random founder per window, 100 = best panel founder per window. Random = exact expectation over the panel founders scorable in each window. Better / worse at ≥ 1 point change.
  • Gene-window error %: errors ÷ called truth bases in gene ±5 kb windows. Per event: mismatches + indel events + unaligned runs (one 45 bp deletion = 1). Per bp: every mismatched, inserted, deleted and unaligned base, capped at the window's called bases. Ceiling = best single panel founder per window under the same counting. Per event is the primary measure (per bp charges every base of an indel). Haplotype windows whose in-panel truth founder's own panel sequence failed extraction are excluded from model, ceiling and random (“truth unextractable”, shown in the Gene window table). Scorer v2 (2026-10-16): when a founder segment's projection onto the founder assembly fails, it is split into 2 kb tiles and only the failed tiles are N (v1 made the whole segment N); the panel ceiling and random baseline use the same rule.
  • Coverage: amber below 95% genome; better / worse at ≥ 1 pp change. An error win in a scope below 95% coverage turns amber, never green.
  • Switch ratio: closer to 1 is better; status from the change in |ln ratio| (≥ 0.10).
  • Verdict: per scope from SNP+RC; a class inside a non-worse scope is a regression at ≥ 10% relative and ≥ 0.02 pp worse. With “both” depths a scope counts only if it moves the same way at both depths, otherwise “mixed”. Green: wins and no losses; red: losses and no wins; amber: mixed or abstaining.
  • Scope values: mean of class SNP+RC and coverage; gene-window error pooled over the scope's windows; switch ratio = Σ model changes ÷ Σ reference changes. “both” averages the two depths.
Corpus: simulated validation, 8 classes × 5 samples
